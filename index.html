    How it works

    AccessLens runs 12 checks based on WCAG 2.2 (images, labels, buttons, links, headings, contrast, language, focus order and more) in your browser. It makes no network requests, and its security policy blocks them, so private or unreleased pages stay private.

    Automated tools catch only some problems. Use the report as a starting point, then test with a keyboard and a screen reader.
